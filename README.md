## Featured Projects

### 1) [Deteksi dan Clustering Ukuran Benih Lele Menggunakan YOLOv8 dan K-Means](https://github.com/AlwanFauzi/finalfixpkl)
Computer vision pipeline for catfish seed detection and size clustering using **YOLOv8**, geometric feature extraction, and **K-Means**. Includes training artifacts, evaluation results, and deployment-style inference outputs.

### 2) [Employee Attrition Analytics Dashboard](https://github.com/AlwanFauzi/idCamp-dashboard-HR)
End-to-end attrition analysis project with **Logistic Regression**, processed datasets, risk scoring for current employees, and a **Metabase** dashboard for HR monitoring.

### 3) [Student Dropout Prediction & Dashboard](https://github.com/AlwanFauzi/idCamp-Dashboard-Jaya-Institut)
Business dashboard and **Streamlit** prediction app for early dropout detection using student performance data and a classification pipeline.

### 4) [Sentiment Analysis of Ruangguru Reviews](https://github.com/AlwanFauzi/DBS-Analisis-Sentimen)
Indonesian text sentiment classification using **CNN** and pretrained embeddings for positive vs negative review prediction.

### 5) [ETL Pipeline - Fashion Product Scraper](https://github.com/AlwanFauzi/DBS-ETL-Pipeline)
ETL project that scrapes product data, transforms and cleans it, then loads the result into **CSV** and **Google Sheets**, with **unit testing** included.

### 6) [Movie Recommendation System](https://github.com/AlwanFauzi/DBS-Sistem-Rekomendasi)
Recommendation system using both **Content-Based Filtering** and **Collaborative Filtering** for personalized movie suggestions.
